
## Project Structure

```
Robotik/

```

## Description

This project is a PID control system implementation and analysis. It demonstrates proportional-integral-derivative (PID) control mechanisms through a robotic system simulation.

## Key Components

- **main.py** - Entry point for running the PID control simulation
- **controller.py** - PID controller implementation
- **robot.py** - Robot model and dynamics
- **utils.py** - Utility functions and helpers

## Requirements

- Python 3.12.5
- NumPy 2.4.2 (for numerical calculations)
- Matplotlib 3.10.8 (for visualization/plotting)
- Pillow 12.1.1 (for image processing)

## Usage

```bash
python main.py
```
